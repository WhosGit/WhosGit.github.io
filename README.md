# Keyuan Hu — Personal Academic Website

Source for [whosgit.github.io](https://whosgit.github.io/).

The site contains:

- an academic homepage with biography, news, and research;
- research, publication, and project records;
- independent English and Chinese PDF CV pages;
- a separate personal blog;
- a Markdown-first blog importer with colocated images and attachments;
- automatic GitHub Pages deployment.

Most updates only require editing files in [`content/`](./content). See
[`MAINTAINING.md`](./MAINTAINING.md) for the Chinese maintenance guide.

## Local preview

```bash
npm install
npm run dev
```

## Validation

```bash
npm run lint
npm run build:github
```
